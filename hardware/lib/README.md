# Component library

Symbols and footprints for the parts on the board. The Tag-Connect, test point and mounting hole entries are
original. The rest were converted from the LCSC/EasyEDA component library with
[easyeda2kicad](https://github.com/uPesy/easyeda2kicad.py) and then edited; that library publishes no licence
of its own. Pad geometry follows each manufacturer's datasheet.

3D models are not included.
